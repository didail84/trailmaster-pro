# Contribuer

Les idées et corrections sont les bienvenues.

- **Un bug ou une idée ?** Ouvre une « Issue » en décrivant ce que tu faisais, ce que tu attendais et ce qui s'est passé (une capture d'écran aide beaucoup). **Ne joins jamais ta base de données** : elle contient tes données de santé et tes clés personnelles.
- **Une modification de code ?** Fais un « fork », crée une branche, puis ouvre une « Pull Request ». Teste d'abord avec `python3 main.py`.
- Les textes de l'interface sont en français. Le code est commenté en français.
- Chaque nouvelle version augmente le nombre du fichier `VERSION` et ajoute une ligne dans `CHANGELOG.md`.
